03 / DOCUMENTATION

Start building with Memer.

Install the CLI, train a checkpoint, and launch your own API.

01 — INSTALL

Install Memer CLI

python -m venv .venv
# Linux / macOS / Termux
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1

pip install -e ".[dev]"
memer --help
02 — TRAIN

Train a model

memer train corpus.txt \
  --output checkpoints/memer.json \
  --epochs 3 \
  --dimension 16 \
  --heads 2
03 — GENERATE

Generate text

memer generate checkpoints/memer.json \
  --prompt "Hello, Memer:" \
  --max-new-tokens 80
04 — SERVE

Start the API

memer serve --host 0.0.0.0 --port 8000

# API health
curl http://127.0.0.1:8000/health
!
Before connecting this site

Configure MEMER_CORS_ORIGINS on your API server to include this website's exact origin. Do not expose an unauthenticated API publicly without understanding the resource and access risks.
